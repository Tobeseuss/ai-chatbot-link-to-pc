پل ارتباطی بین چت‌بات‌های هوش مصنوعی و سیستم‌عامل کاربر (ویندوز/لینوکس) با کلیدهای API، پشتیبانی چند سیستم همزمان و تاریخچه کامل تعاملات.

== Description ==

این افزونه یک REST API امن روی سایت وردپرسی شما ایجاد می‌کند که چت‌بات‌های هوش مصنوعی از طریق آن می‌توانند با اجرای برنامه «ایجنت» روی سیستم شما (ویندوز یا لینوکس)، فرمان اجرا کنند، فایل ببینند/ویرایش کنند، برنامه نصب کنند، فایل دانلود/آپلود کنند و مرورگر را اجرا کنند.

ویژگی‌ها:

* ساخت چند کلید API همزمان از پنل مدیریت
* اتصال چند سیستم به یک کلید با شناسه یکتا برای هر سیستم
* سه حالت تعامل برای هوش مصنوعی‌ها: REST API کامل (POST/GET)، حالت relay برای چت‌بات‌های فقط-متنی، و **دروازه URL** (اصل اساسی ۵): دستور در انتهای آدرس قرار می‌گیرد، آدرس باز می‌شود و نتیجه در همان صفحه دیده و پردازش می‌شود (`GET /url/run` و `GET /url/result`) — از نسخه 2.1.0 دستورات متنی پیچیده باید با **Base64 کدشده** در `cmd64` فرستاده شوند تا آدرس URL خراب نشود
* صف فرمان‌ها + دریافت نتیجه (تک‌فرمانی و همزمان با long-poll)
* انتقال فایل دوطرفه (چت‌بات به سیستم و سیستم به چت‌بات) با لینک دانلود امضاشده
* گفتگوی مستقیم کاربر با هوش مصنوعی از طریق ایجنت (`python aclp_agent.py chat`)
* تاریخچه کامل تعاملات: فرمان، نتیجه، فایل‌ها، مدت اجرا
* تنظیمات نگهداری: مدت نگهداری تاریخچه/فایل‌ها، سقف ردیف‌ها، حجم فایل
* محدودیت نرخ درخواست برای هر کلید و ذخیره‌سازی هش کلید

== Installation ==

1. پوشه افزونه را در `wp-content/plugins/` آپلود کنید و افزونه را فعال کنید.
2. از منوی «AI-PC Link → کلیدهای API» یک کلید بسازید.
3. برنامه ایجنت Python را روی سیستم خود اجرا کنید و آدرس سایت و کلید را وارد کنید.
4. راهنمای کامل: docs/USER-GUIDE.fa.md در مخزن پروژه.

== Changelog ==

= 2.1.0 =
* **کدگذاری دستورات در دروازه URL (توسعه اصل اساسی ۵ — درخواست مالک):** دستورات متنی پیچیده (کوتیشن، &، |، >، خط جدید، نویسه‌های غیر ASCII) نباید خام در URL قرار بگیرند؛ پارامتر جدید `cmd64` (مستعار `b64`) دستور را به‌صورت **Base64** می‌پذیرد و سرور خودکار دیکد می‌کند
* سه شکل Base64 پذیرفته می‌شود: URL-safe (توصیه‌شده: + → - ، / → _ ، بدون پدینگ)، استاندارد خام و استاندارد percent-encoded؛ خطای دیکد با پیام انگلیسی واضح در صفحه گزارش می‌شود
* پارامتر `payload64` برای JSON پیچیده هم اضافه شد؛ `/ping` فیلد جدید `url_gate_cmd64` را برمی‌گرداند
* متن اصل ۴ (MODE C) و صفحه راهنمای دروازه URL قاعده «دستور پیچیده ⇒ Base64» را به ایجنت‌ها آموزش می‌دهند

= 2.0.0 =
* **دروازه URL (اصل اساسی ۵):** حالت سوم تعامل — دستور در انتهای URL، نتیجه در همان صفحه (text/plain؛ با &format=json هم JSON)
* دو مسیر جدید: `GET /url/run` (ثبت + انتظار تا ۲۵ ثانیه + گزارش در همان صفحه) و `GET /url/result` (بررسی نتیجه با ticket)
* متن اصل ۴ حالت MODE C را توضیح می‌دهد؛ `/ping` فیلد `url_gate` را برمی‌گرداند
* افزایش نسخه اصلی (Major) به درخواست مالک

= 1.0.0 =
* انتشار اولیه: هسته پلاگین، REST API کامل، پنل مدیریت فارسی، ایجنت پایتون کراس‌پلتفرم.
